# coarse-kpath
Script for generating a coarsely sampled k-point path for VASP band structure calculations.

## Installation

```
git clone https://github.com/MiloCarroll/coarse-kpath/
cd coarse-kpath
pip install .
```

This installs the `get_coarse_kpath` command. Use `pip install -e .` instead if you want `git pull` to update the installed command without reinstalling.
